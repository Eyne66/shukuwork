关于 / About

LibSchedPay

基于 github.com/Eyne66/LibSchedPay，由 MiniMax Agent 制作部署。

这是一个什么工具

校园书库学生助理排班 + 工时转账的本地工作台。负责人填数据 → 脚本算 → 表格预览改 → 校验 → 导出 Excel。

能力

  • 排班：周期、班次、硬约束、30–40 人名单；按班岗时长分别平衡；导出 Excel
  • 工时转账：实际工时、官方下发工时逐人编辑；差值自动算；配平 + 校验；转账表 + 公示表 + 一览表 + 草案
  • 校验：硬约束违反、缺岗、超员、未配平全部报错，不让伪成品导出

不做什么

  • 不替你做软偏好（"尽量和某人一起""优先晚班"——草稿里人工调）
  • 不计算时薪、人民币金额、税费或银行付款
  • 不替你猜未填的下发工时，必须人确认
  • 不上传任何数据到服务器，所有计算在浏览器本地完成
